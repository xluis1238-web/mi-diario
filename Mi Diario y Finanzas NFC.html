¿Cómo usar esta Web con un Tag NFC?

1. Aloja este archivo HTML en un servicio gratuito como GitHub Pages, Vercel o Netlify.
2. Copia la URL de tu página web (ejemplo: https://mi-diario.vercel.app).
3. Usa una app gratuita en tu móvil como NFC Tools (iOS/Android).
4. Selecciona Escribir -> Añadir un registro -> URL / URI y pega el enlace de tu web.
5. Toca Escribir y acerca tu etiqueta NFC. ¡Listo! Cada vez que acerques tu teléfono al NFC se abrirá esta aplicación automáticamente.
